# Corpo em Foco — Avaliação Corporal

## Sobre o projeto

O Corpo em Foco é um aplicativo web desenvolvido para auxiliar alunos no acompanhamento de informações corporais, oferecendo uma estimativa do percentual de gordura corporal com base em idade, altura, peso e sexo biológico.

O projeto foi desenvolvido como atividade acadêmica, utilizando tecnologias de desenvolvimento web.

## Objetivo

Desenvolver uma aplicação simples, intuitiva e acessível que permita cadastrar alunos, inserir informações corporais e visualizar resultados estimados.

## Funcionalidades

- Cadastro de alunos.
- Login de acesso.
- Conta para demonstração.
- Registro de idade, altura e peso.
- Estimativa do percentual de gordura corporal.
- Cálculo do Índice de Massa Corporal (IMC).
- Visualização do último registro.

## Tecnologias utilizadas

- HTML5 — estrutura do site.
- CSS3 — estilização e layout.
- JavaScript — funcionalidades e cálculos.
- LocalStorage — armazenamento local dos dados.

## Cálculo corporal

O sistema utiliza uma fórmula matemática baseada no IMC, idade e sexo para apresentar uma estimativa do percentual de gordura corporal.

O resultado é aproximado e não substitui uma avaliação realizada por um profissional de saúde.

## Armazenamento

Nesta versão demonstrativa, os cadastros e avaliações são armazenados no próprio navegador por meio do LocalStorage. Os dados não são sincronizados entre dispositivos.
